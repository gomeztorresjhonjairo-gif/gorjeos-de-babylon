# Prompts para imágenes de servicios

## Dirección visual común

Usar imágenes horizontales 4:3 para la zona superior de cada tarjeta. Mantener una estética editorial tecnológica, limpia y sobria: fondo marfil, azul noche y acentos naranja cálido, iluminación suave, composición con espacio negativo, formas precisas y sensación de producto premium. No incluir texto, letras, logotipos, marcas de agua, interfaces ilegibles ni rostros deformados.

## 1. Websites + embudo digital

`Editorial 3D still life about digital conversion: a luminous orange path made of connected geometric steps guiding small points of light toward a clear central destination, subtle navy shadows, warm ivory background, premium technology studio aesthetic, clean composition, soft studio lighting, horizontal 4:3, no text, no logo, no watermark.`

## 2. Apps y software empresarial

`Editorial 3D visualization of an organized digital operation: modular translucent blocks, connected data pathways and a central structural dashboard represented abstractly, orange highlights, deep navy details, warm ivory background, precise architectural composition, premium technology studio aesthetic, horizontal 4:3, no text, no logo, no watermark.`

## 3. Auditoría de ciberseguridad

`Editorial 3D visualization of digital protection: a refined orange shield-shaped light structure surrounding a secure geometric core, subtle circuit lines and navy depth, warm ivory background, calm trustworthy atmosphere, premium cybersecurity studio aesthetic, horizontal 4:3, no text, no logo, no watermark.`

## 4. Revisión UX / UI

`Editorial 3D visualization of frictionless user experience: smooth flowing surfaces connecting in a single elegant path, one orange focal point moving through the composition, navy accents, warm ivory background, balanced negative space, premium design studio aesthetic, horizontal 4:3, no text, no logo, no watermark.`

## 5. Modelos y personajes con IA

`Editorial 3D visualization of creative artificial intelligence: an abstract luminous character silhouette formed by refined orange particles and geometric shapes, subtle navy structure, warm ivory background, imaginative but sophisticated, premium creative technology studio aesthetic, horizontal 4:3, no text, no logo, no watermark.`

## Prompt negativo común

`text, typography, letters, logo, watermark, brand name, interface screenshot, stock photo look, excessive neon, saturated rainbow colors, clutter, noisy background, distorted geometry, malformed hands, duplicated objects, low resolution.`

## Exportación recomendada

- Formato: WebP o AVIF.
- Proporción: 4:3.
- Ancho inicial: 1200 px.
- Peso objetivo: menos de 180 KB por imagen después de optimizar.
- Mantener una copia original aparte y no incrustar texto dentro de la imagen.
